# Инструкция по запуску проекта на обычном ПК

Учебный портал и интерактивная презентация: **«Современные информационные угрозы и методы противодействия атакам»**  
(Академия МВД Республики Казахстан, 4 курс, специальность «Информационные системы и ИИ»).

---

## Вариант 1. Быстрый запуск в режиме разработчика (Рекомендуется)

### Шаг 1. Установите Node.js (если еще не установлен)
1. Скачайте бесплатный установщик **Node.js (LTS)** с официального сайта: [https://nodejs.org/](https://nodejs.org/)
2. Установите его, нажимая «Далее» (Next) со стандартными настройками.

### Шаг 2. Запуск на Windows (в 1 клик)
В папке с проектом дважды кликните по файлу **`start.bat`**.  
Скрипт сам установит зависимости и откроет сайт в вашем браузере!

---

### Либо через командную строку вручную (Windows / macOS / Linux):

1. Откройте терминал (**PowerShell**, **Командная строка** или **Терминал macOS/Linux**) в папке с проектом.
2. Установите необходимые библиотеки (выполняется 1 раз):
   ```bash
   npm install
   ```
3. Запустите локальный сервер:
   ```bash
   npm run dev
   ```
4. Откройте в любом браузере (Chrome, Edge, Яндекс, Firefox) адрес:
   ```
   http://localhost:3000
   ```

---

## Вариант 2. Сборка автономной версии для флешки (Offline)

Если вам нужно принести презентацию на экзамен или защиту на флешке на компьютер **без интернета**:

1. В папке проекта выполните сборку:
   ```bash
   npm run build
   ```
2. В проекте появится папка **`dist/`** — это полностью готовый автономный сайт со всеми слайдами, стилями и изображениями.
3. Для ее демонстрации можно запустить:
   ```bash
   npx serve dist
   ```
   или просто использовать команду `npm run preview`.

---

## Горячие клавиши для презентации перед комиссией:
* **F** — переход в полноэкранный режим и обратно
* **Пробел** или **Стрелка вправо (→)** — следующий слайд
* **Стрелка влево (←)** — предыдущий слайд
* **Esc** — выход из режима презентации обратно на сайт
* Кнопка **«Заметки докладчика»** — открывает подготовленную речь к каждому слайду.
